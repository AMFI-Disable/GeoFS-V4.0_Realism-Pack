# GeoFS-V4.0_Realism-Pack

The standalone Realism Pack module for the GeoFS-V4.0 ecosystem, unifying HUD instrumentation under GeoFS-V3.9 minimalistic design.

## Features

- Integrates into the unified, persistent glassmorphic HUD managed by the GeoFS-V4.0 Core Library.
- Retains the proven GeoFS-V3.9 neutral aesthetics (`rgba(0,0,0,0.8)`, `border: 1px solid #888`, `border-radius: 15px`).
- Compatible with GeoFS V4.0 on `beta.geo-fs.com` and `www.geo-fs.com`.

## Installation

Install via Tampermonkey or your preferred userscript manager.
